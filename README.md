# SmartRapport

## Projektbeschreibung

SmartRapport ist ein Semesterprojekt im 1. Semester Programmieren.

Ziel des Projekts ist es, den bisherigen Stundenrapport zu digitalisieren.
Mitarbeitende sollen ihre geleisteten Arbeitsstunden digital erfassen und verwalten können.
